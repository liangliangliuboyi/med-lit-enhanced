## B 组 · 证据质量与可信度

| # | 问题 | 现状 | 建议改法 | 工作量 | 优先级 | 你的选择 |
|---|---|---|---|---|---|---|
| B1 | **GRADE 定级全靠模型主观判断** | critic 模型直接给「高/中/低/极低」，没有机械依据 | 程序侧做机械定级：研究设计→起始等级（RCT 高、横断面低），按一致性/不精确性/偏倚风险自动降级；模型只在机械规则之上做一次复核 | 中 | 🔴 高 | |
| B2 | **不查撤稿与更正** | 引用了被撤稿的论文是大忌，现在完全不管 | 从 PubmedData 读 `PublicationType` 里的 `Retracted Publication` / `Published Erratum`，命中就在证据表和答案里红字警告 | 小 | 🔴 高 | |
| B3 | **不抽取偏倚评估要素** | 只抽作者自述的 limitations，没有 PRISMA / RoB 需要的结构化项（随机化、盲法、分配隐藏、随访时长、失访率） | 在 reader 提示词里加 6 个结构化字段，程序侧汇总成偏倚要素表 | 中 | 🟠 中 | |
| B4 | **效应量只做定性综合** | 8 篇文献的 RR/OR/HR 各说各的，没有合并 | 同质性够时，程序侧做固定效应/随机效应合并（逆方差加权），产出合并效应量 + 异质性 I² | 中大（要自己实现统计） | 🟠 中 | |
| B5 | **不判断「该文献是否真的支持这句话」** | 只校验 PMID 在不在候选池，不管内容对不对 | 对答案里每个「PMID + 论断」做一次语义比对（第二次模型调用，成本翻倍） | 小代码 / 大成本 | 🟡 低（可选） | |
| B6 | **没有直接证据/间接证据区分** | PICO 不完全匹配的文献和完全匹配的混在一起 | 抽取时加一个 PICO 匹配度（完全/部分/间接），写答案时分开呈现 | 小 | 🟠 中 | |
| B7 | **图表没抓** | PMC 全文只取文字，森林图/漏斗图/曲线丢掉 | 从 BioC 里抽 figure caption，必要时抓图片 URL | 中 | 🟡 低 | |
| B8 | **相关度打分没有交叉验证** | 模型自己给 1–5 分 | 两个不同模型各打一次取平均（成本翻倍） | 小代码 / 大成本 | 🟡 低（可选） | |

## 我这边的判断

> 这个技能**架构上没问题**，三条纪律（只依据真实文献、参考文献由脚本生成、不够就说不够）是对的，
> 11 条降级路径和全程留痕是它比同类工具强的地方。
>
> 真正的短板在**检索覆盖**和**输出可用性**两块：
> 检索侧没有质量闸门（A1）、不查撤稿（B2）、没有预印本（A4）、没有中文文献（A5）；
> 输出侧没法直接进论文（C1/C2）。
>
> 另外它现在**只服务 PubMed 英文文献**这一点，你做开源要面对的使用者多半是中文医学生，
> 他们真正缺的可能恰恰是中文文献——这块要不要补，是这个项目「值不值得被用起来」的关键判断，
> 我倾向先在 README 里**诚实声明边界**，等有合适的授权渠道再接。
