# 示例输出

这里是**一次真实运行**的脱敏产物（2026-11-06）。
问题：「GLP-1 受体激动剂对青少年肥胖的疗效与安全性如何？」

| 文件 | 内容 |
|---|---|
| `07_answer.md` | 答案正文（八段式，每条论断挂 PMID） |
| `05_evidence_table.md` | 证据总表 + 偏倚要素表 + 合并效应量 + GRADE 机械定级 |
| `08_bibliography.md` | 参考文献（由脚本按 PubMed 原始字段生成） |
| `11_prisma.md` | PRISMA 流程计数 + 排除理由汇总 + 全部检索式明细 |
| `10_trace.json` | 模型命中、各阶段耗时、成本、错误表、引用校验结果（已去除本机路径） |

## 这份示例值得看什么

1. **证据是真的**：命中 3276 条、筛出 35 篇候选、精读 5 篇，
   设计分布是 **RCT 2 篇 + 系统综述 3 篇**，
   期刊是 *JAMA*、*JAMA Pediatrics*、*NEJM*、*Lancet*、*Diabetes Obesity & Metabolism*。
2. **冲突被摆出来而不是抹平**：司美格鲁肽的 BMI 变化（-16.7 个百分点）
   与利拉鲁肽（-7.4 个百分点）差距被直接写出，并解释可能来自药物类型、剂量、给药方式。
3. **异质性被量化**：SMD 合并后 I²=93%，GRADE 因此从「高」降到「中」，
   降级理由写进答案而不是藏在后台。
4. **证据空隙说得清楚**：缺乏长期停药后复发数据、缺乏 6–12 岁儿童安全性数据、
   缺乏头对头比较——直接写进「证据空隙」一段。
5. **适用边界明确**：只适用于 12–18 岁、BMI≥第95百分位、常伴共存疾病的肥胖青少年，
   并声明「不能在所有 GLP-1 受体激动剂中直接通用」。
6. **中文文献的边界被主动交代**：「检索范围限于国际英文文献，未覆盖中文数据库中的研究」。
7. **可审计**：参考文献由脚本生成，模型碰不到期刊名和年份；
   `10_trace.json` 里能看到每个阶段的耗时、token、成本与错误表。

## ⚠️ 这份示例是「修好一个严重 bug 之后」重跑的

早期版本的证据池里**全是动物与机制研究**（期刊是 *Cells*、*Cell biochemistry and function*），
却被当作人体疗效证据呈现。原因是 PubMed 的动物排除过滤器写法有语义反转
（详见 `docs/功能改进清单.md` 的 Q1' 与 R1）。

> **所以看这份示例时，请对照 `10_trace.json` 里的 `models` 与 `timings`**——
> 它们能让你看到每个阶段实际用了哪个模型、花了多少秒、成本多少。

- 未放入 `03_papers.json`（含 PubMed 摘要，属 PubMed 内容）

## 复现

```bash
python scripts/ask.py "GLP-1 受体激动剂对青少年肥胖的疗效与安全性如何？" \
  --constraints "人群为青少年或年轻人；2015 年后" --max-papers 5
```

⚠️ 这条查询的实际耗时约 **8.5 分钟**，成本约 **¥0.076**（一次完整运行包含约 20 次模型调用：
规划 + 检索 + 5 篇精读 + 相关度交叉验证 + 审查 + 成文 + 结构重写 + 语义比对）。

`10_trace.json` 里能看到 13 个阶段的耗时与成本明细，可以自己核对每一秒花在哪。

想快速看效果加 `--quick`（会关掉交叉验证与语义比对，耗时和成本都明显下降）。
