# 示例输出

这里是**一次真实运行**的脱敏产物（2026-11-05，NCBI 恢复正常后跑的）。
问题：「GLP-1 受体激动剂对青少年肥胖的疗效与安全性如何？」

| 文件 | 内容 |
|---|---|
| `07_answer.md` | 答案正文（八段式，每条论断挂 PMID） |
| `05_evidence_table.md` | 证据总表 + 偏倚要素表 + 合并效应量 + GRADE 机械定级 |
| `11_prisma.md` | PRISMA 流程计数 + 排除理由汇总 + 全部检索式明细 |
| `10_trace.json` | 模型命中、各阶段耗时、错误表、引用校验结果（已去除本机路径） |

## 这份示例值得看什么

1. **诚实**：结论第一句就是「尚无直接针对青少年肥胖人群的高质量临床研究证据」，
   并明确写了「这些发现**不能直接适用于青少年肥胖的临床决策**」。
2. **直接证据与间接证据分开**：成人研究、动物模型、机制研究各自成段并标注，
   没有把小鼠减重 25% 当成青少年的疗效。
3. **中文文献的边界被主动交代**：「本轮检索未覆盖中文文献，需注意中国国内的相关指南
   可能包含不同的推荐意见」——这是工具写进 writer 提示词的硬性纪律。
4. **检索覆盖说明**：交代了覆盖了什么、**没覆盖什么**（青少年人群、长期数据、亚组）。
5. **可审计**：参考文献由脚本按 PubMed 原始字段生成，模型碰不到期刊名和年份。
